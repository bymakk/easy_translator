# Easy Translator — журнал изменений

Версия **0.0.165** · 5 мая 2026

---

1. Добавление иконки для вызова основного окна переводчика в Inline Popup. Дает возможность «предпросмотра» перевода текста, который пользователь ввел в поле для ввода, и его корректировки.

2. Очередное исправление функции запоминания размера окна.
3. Очередной фикс резкого изменения размера окна при перетаскивании за иконку изменения размера.
4. Исправление ширины выпадающего списка языков во Inline Popup: ширина по самому длинному названию языка.
5. Исправлен баг в чатах x.com (Twitter): при клике по полю ввода без выделения текста открывалось окно переводчика.
